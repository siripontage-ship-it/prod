ตั้งค่าการเชื่อมต่อ

เสียบ ESP32 เข้ากับโน้ตบุ๊คด้วยสาย Micro USB แล้วกดปุ่มด้านล่าง — เบราว์เซอร์จะเปิดหน้าต่างให้เลือกพอร์ต (COMx) รองรับเฉพาะ Chrome หรือ Edge เท่านั้น และต้องปิดหน้าต่าง Serial Monitor ใน Arduino IDE ก่อน ไม่งั้นจะเชื่อมต่อไม่ติด เพราะพอร์ตเดียวใช้พร้อมกันสองโปรแกรมไม่ได้

ใช้วิธีนี้เมื่อ ESP32 เชื่อมต่อ WiFi และส่งค่าขึ้น Blynk Cloud อยู่แล้ว (ตามโค้ด Blynk.virtualWrite(...) ในสเก็ตช์) หน้านี้จะดึงค่า ล่าสุดจาก Blynk Cloud มาแสดงผลโดยตรง ไม่ต้องเสียบสาย USB
